# Flow Free

A free, mobile-friendly income and expense tracker. No account required.

## Open the app

After GitHub Pages is enabled: https://genmagnum.github.io/flow-free/

## Enable hosting

Open repository Settings → Pages. Under Build and deployment choose Deploy from a branch, main, /(root), then Save.

## Use on your phone

Open the published link in Safari on iPhone or Chrome on Android and choose Add to Home Screen (or Install app).

## Privacy and backups

Financial records and receipt images stay in this browser on this device. GitHub hosts only the app files. This edition has no automatic cloud sync. Export a backup regularly and import it on another device to transfer your records. Clearing browser storage can remove your records.

Receipt text recognition uses Tesseract resources downloaded on demand and needs internet access for the initial download. Review recognized values before saving.
